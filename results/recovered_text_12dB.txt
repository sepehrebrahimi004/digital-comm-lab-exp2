A digital communication system turns a message into a stream of bits, protects those bits, maps them onto waveforms and sends them through a noisy channel. At the receiver every step is undone in reverse order. Source coding removes redundancy so that fewer bits have to be sent, and channel coding adds structured redundancy back so that errors caused by noise can be detected and corrected. Modulation decides how many bits each transmitted symbol carries; denser constellations save bandwidth but need a stronger signal for the same error rate.
